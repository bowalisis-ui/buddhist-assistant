# 📿 讀經陪伴小助手 (Buddhist Scripture Companion App)

> **陪伴您深研經典實相大智慧的輕量級 Web 應用程式與全典籍知識庫。**

---

## ✨ 專案亮點與特色 (Features)

### 1. 📖 20 大經典全典籍收錄 (漢傳大乘八宗全典籍大圓滿收錄)
本系統嚴謹收錄漢傳大乘八宗（淨土宗、禪宗、天台宗、華嚴宗、法相唯識宗、三論宗、律宗、密宗）共 20 部核心經典與論頌全文，並依傳統佛學科判進行章節細分：
- **淨土宗**：《佛說無量壽經》、《佛說阿彌陀經》、《佛說觀無量壽佛經》、《大勢至菩薩念佛圓通章》
- **禪宗**：《六祖大師法寶壇經》、《信心銘》、《永嘉證道歌》
- **天台宗**：《妙法蓮華經》（二十八品全）、《修習止觀坐禪法要》(天台小止觀，十科全)
- **華嚴宗**：《大方廣佛華嚴經·普賢行願品》（含十大願王偈頌）
- **法相唯識宗**：《解深密經》（八品全）、《唯識三十論頌》（玄奘譯）
- **三論宗 (中觀)**：《中論》（龍樹菩薩造，含觀因緣品、觀四諦品、觀涅槃品）
- **律宗 (戒律)**：《佛遺教經》（佛陀最後教誡）、《梵網經菩薩戒本》（十重大戒）
- **密宗 (真言)**：《大日經·住心品》（唐善無畏譯）、《大悲心陀羅尼經》（觀音大悲咒）
- **般若與圓頓**：《大佛頂首楞嚴經》（十卷全）、《金剛般若波羅蜜經》（三十二分全）、《般若波羅蜜多心經》（七科全）

### 2. 📿 經典名句金輝突顯 (Golden Glow Badges)
- 經文中出現經典名句（如「凡所有相，皆是虛妄」、「應無所住，而生其心」、「色不異空，空不異色」、「菩提本無樹」、「狂心頓歇，歇即菩提」等）時，自動呈現尊貴 **📿 金輝流光徽章**。
- 點擊名句徽章可立即展開 AI 側欄，查看微旨解讀與實相開示。

### 3. 🔖 讀經書籤與進度記憶 (Bookmark Management)
- **段落標記 (📌)**：閱讀經文時點擊段落旁圖示即可加入個人書籤。
- **讀經書籤頁籤 (🔖)**：集中展示標記重點段落、閱讀時間與預覽，支援一鍵精確跳轉。
- **自動記憶閱讀進度**：自動記錄上次閱讀之經典與章節。

### 4. 📚 佛學名詞與教理手冊 (Categorized Glossary)
- 嚴謹按**佛法教理脈絡**分區歸類（共 100+ 筆資料）：
  1. **一、核心教理與宇宙觀**（四聖諦細項、十二因緣 12 支鏈條、三法印、緣起性空）
  2. **二、心性與實相（般若系）**（般若、五蘊細項、四相細項、無住、常住真心、七處徵心、八還辨見）
  3. **三、修行與境界（菩薩道）**（菩提、菩薩、六度細項、三輪體空、十大弟子）
  4. **四、煩惱與業力**（三毒細項、業、涅槃、客塵煩惱、五十陰魔）
  5. **五、大乘重要經典與法華七喻**（火宅喻、窮子喻、藥草喻、化城喻、衣珠喻、鑿井喻、醫子喻等）
  6. **🌸 經典名句與法言偈頌**

### 5. 🤖 AI 讀經小助手 (Progressive AI Assistant)
- 支援經文點擊高亮名詞即時解義。
- 詢問新問題時，AI 小助手會為您分析解答並自動納入辭典庫中。

## 🚀 快速啟動 (Quick Start)

### 1. 安裝依賴
```bash
cd reader_app
npm install
```

### 2. 設定 Gemini API 金鑰 (啟用 AI 讀經小助手)
請在 `reader_app` 目錄下將 `.env.example` 複製為 `.env.local` 檔案，並填入您的 Gemini API 金鑰：
```bash
# 在 reader_app 目錄下建立 .env.local 檔案
VITE_GEMINI_API_KEY=your_gemini_api_key_here
```
> ⚠️ **重要安全提醒**：請務必將個人的 API Key 儲存在 `.env.local` 中（該檔案已被 `.gitignore` 排除），切勿將真實金鑰直接提交 (commit) 至 GitHub！

### 3. 啟動開發伺服器
- **方式一 (桌面捷徑/批次檔一鍵啟動)**：雙擊桌面上的 **「讀經陪伴小助手」** 捷徑，或雙擊根目錄下的 [`啟動讀經助手.bat`](file:///c:/AI%20Agent/%E8%AE%80%E7%B6%93%E5%8A%A9%E6%89%8B/%E5%95%9F%E5%8B%95%E8%AE%80%E7%B6%93%E5%8A%A9%E6%89%8B.bat)。
- **方式二 (終端機啟動)**：
  ```bash
  cd reader_app
  npm run dev
  ```

瀏覽器開啟 [http://localhost:5173/](http://localhost:5173/) 即可開始閱讀與使用！
