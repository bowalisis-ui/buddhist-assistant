# 📿 讀經陪伴小助手 (Buddhist Scripture Companion App)

> **陪伴您深研經典實相大智慧的輕量級 Web 應用程式與全典籍知識庫。**

---

## ✨ 專案亮點與特色 (Features)

### 1. 📖 10 大經典全典籍收錄 (無缺漏、無截斷)
本系統嚴謹收錄大乘、禪宗與淨土宗共 10 部核心經典全文，並依傳統佛學科判進行章節細分：
- **《大佛頂首楞嚴經》**（卷一 至 卷十）
- **《妙法蓮華經》**（卷一 至 卷七，二十八品全）
- **《金剛般若波羅蜜經》**（昭明太子三十二分全）
- **《佛說無量壽經》**（上卷四十八大願、下卷三輩往生）
- **《佛說阿彌陀經》**（序分、正宗分持名念佛、流通六方讚歎全）
- **《佛說觀無量壽佛經》**（十六觀與九品往生全）
- **《般若波羅蜜多心經》**（佛學傳統七科分章全）
- **《六祖大師法寶壇經》**（傳統十品全）
- **《信心銘》**（四科分章全）
- **《永嘉證道歌》**（六科分章全）

### 2. 📿 經典名句金輝突顯 (Golden Glow Badges)
- 經文中出現經典名句（如「凡所有相，皆是虛妄」、「應無所住，而生其心」、「色不異空，空不異色」、「菩提本無樹」、「狂心頓歇，歇即菩提」等）時，自動呈現尊貴 **📿 金輝流光徽章**。
- 點擊名句徽章可立即展開 AI 側欄，查看微旨解讀與實相開示。

### 3. 🔖 讀經書籤與進度記憶 (Bookmark Management)
- **段落標記 (📌)**：閱讀經文時點擊段落旁圖示即可加入個人書籤。
- **讀經書籤頁籤 (🔖)**：集中展示標記重點段落、閱讀時間與預覽，支援一鍵精確跳轉。
- **自動記憶閱讀進度**：自動記錄上次閱讀之經典與章節。

### 4. 📚 佛學名詞與教理手冊 (Categorized Glossary)
- 嚴謹按**佛法教理脈絡**分區歸類（共 100+ 筆資料）：
  1. **一、核心教理與宇宙觀**（四聖諦細項、十二因緣 12 支鏈條、三法印、緣起性空）
  2. **二、心性與實相（般若系）**（般若、五蘊細項、四相細項、無住、常住真心、七處徵心、八還辨見）
  3. **三、修行與境界（菩薩道）**（菩提、菩薩、六度細項、三輪體空、十大弟子）
  4. **四、煩惱與業力**（三毒細項、業、涅槃、客塵煩惱、五十陰魔）
  5. **五、大乘重要經典與法華七喻**（火宅喻、窮子喻、藥草喻、化城喻、衣珠喻、鑿井喻、醫子喻等）
  6. **🌸 經典名句與法言偈頌**

### 5. 🤖 AI 讀經小助手 (Progressive AI Assistant)
- 支援經文點擊高亮名詞即時解義。
- 詢問新問題時，AI 小助手會為您分析解答並自動納入辭典庫中。

## 🛠️ 技術棧 (Tech Stack)

- **前端框架**：React 18 + Vite
- **圖示庫**：Lucide React
- **樣式設計**：Vanilla CSS（深色禪意沉浸風、雙重高光色系）
- **版本控制**：Git + GitHub Private Repository

## 🚀 快速啟動 (Quick Start)

### 1. 安裝依賴
```bash
cd reader_app
npm install
```

### 2. 啟動開發伺服器
```bash
npm run dev
```
瀏覽器開啟 `http://localhost:5173/` 即可開始閱讀與使用！
